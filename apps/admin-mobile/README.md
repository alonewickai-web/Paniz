# PanizStyle Admin | Android

اپ Flutter برای مدیریت فروشگاه PanizStyle است. برنامه از API مرکزی استفاده می‌کند و به پایگاه داده اتصال مستقیم ندارد.

## قابلیت‌های متصل به API

- ورود مدیر با نام کاربری و گذرواژه؛ ورود با شمارهٔ همراه مدیر برای حساب‌های قدیمی نیز پذیرفته می‌شود.
- راه‌اندازی یک‌بارهٔ مدیر مالک با کلید محرمانهٔ سرور و گذرواژهٔ دست‌کم ۱۲ نویسه.
- نگهداری نشست در secure storage و خروج از نشست جاری.
- تغییر نام کاربری یا گذرواژه با تأیید گذرواژهٔ فعلی؛ تغییر اطلاعات ورود همهٔ نشست‌های مدیریتی را باطل می‌کند.
- هش گذرواژهٔ مدیر با Argon2id؛ هش‌های scrypt قدیمی بعد از ورود موفق به Argon2id ارتقا می‌یابند.
- داشبورد فروش واقعی، سفارش‌های تازه و هشدارهای موجودی.
- فهرست، ثبت، ویرایش، انتشار/پیش‌نویس و بایگانی محصول و تنوع‌های رنگ و سایز.
- مشاهده و اصلاح موجودی با ثبت دلیل در گردش انبار.
- مشاهدهٔ سفارش‌ها و تغییر وضعیت در مسیر مجاز Backend؛ هنگام ثبت ارسال، کد رهگیری لازم است.
- مدیریت دسته‌ها، بنرها، رنگ سایت و بخش‌های صفحهٔ اصلی.
- پنج بخش اصلی در نوار پایین: خانه، سفارش‌ها، محصولات، آمار و بیشتر؛ ابزارهای کم‌استفاده در منوی سمت راست قرار دارند.

مدیریت مشتریان، کد تخفیف و تبلیغات، TOTP، فهرست دستگاه‌های فعال، تاریخچهٔ کامل امنیتی، اثر انگشت و گزارش نمودار روزانه هنوز به API متصل نیستند و در اپ با وضعیت روشن مشخص شده‌اند.

## ساخت Android

پروژهٔ Android آماده است. برای ساخت APK دیباگ:

```powershell
cd apps/admin-mobile
flutter pub get
flutter build apk --debug
```

خروجی در `build/app/outputs/flutter-apk/app-debug.apk` قرار می‌گیرد. این نسخه با کلید دیباگ امضا شده و برای انتشار در فروشگاه برنامه نیست.

نشانی پیش‌فرض API یعنی `10.0.2.2` فقط از Android Emulator به رایانهٔ میزبان وصل می‌شود. برای گوشی واقعی، APK را با IP رایانه در شبکهٔ محلی بسازید و API را برای اتصال شبکه در دسترس قرار دهید؛ نمونه: `flutter build apk --debug --dart-define=PANIZ_API_BASE_URL=http://192.168.1.20:4000/api/v1/ --dart-define=PANIZ_WEB_BASE_URL=http://192.168.1.20:3000/`. دسترسی فایروال را هم بررسی کنید. اجازهٔ HTTP فقط در manifest مخصوص دیباگ فعال است؛ نسخهٔ انتشار به API با HTTPS نیاز دارد.

## راه‌اندازی مدیر و پایگاه داده

کلید `ADMIN_BOOTSTRAP_KEY` را محرمانه در تنظیمات API قرار دهید و مدیر مالک را فقط یک‌بار از صفحهٔ «راه‌اندازی اولیهٔ مدیر» ایجاد کنید. نام کاربری اولیه در فرم `erfan` است و قابل تغییر است؛ گذرواژه داخل برنامه یا APK ذخیره نشده و در فرم راه‌اندازی باید توسط مدیر تعیین شود.

پیش از اجرای نسخهٔ تازهٔ API، migration پوشهٔ `apps/api/prisma/migrations/20261010130000_admin_usernames` را با فرمان `npm run prisma:migrate:deploy` اعمال کنید. هش‌های scrypt مدیران فعلی پس از نخستین ورود موفق به Argon2id تبدیل می‌شوند.

برای بازسازی APK، Flutter و Android SDK نصب باشند و فرمان‌های بالا در پوشهٔ `apps/admin-mobile` اجرا شوند.
