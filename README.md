# PanizStyle

فروشگاه فارسی و راست‌چین پوشاک زنانه با وب‌سایت Next.js، API مستقل NestJS و پایگاه دادهٔ MySQL. سایت و API از یک کاتالوگ مرکزی برای قیمت و موجودی استفاده می‌کنند.

## اجرای محلی در ویندوز

برای شروع، Docker Desktop را باز کنید و روی `Start.bat` در پوشهٔ اصلی پروژه دوبار کلیک کنید. راه‌انداز دیتابیس را با Docker بالا می‌آورد، migration و کاتالوگ نمونه را آماده می‌کند، API و سایت را اجرا می‌کند، Chrome را روی `http://127.0.0.1:3000` باز می‌کند و سپس خودش بسته می‌شود. گزارش‌ها در پوشهٔ `logs` هستند.

برای توقف سرویس‌ها، فرایندهای Node را ببندید و کانتینر محلی MySQL را از Docker Desktop متوقف کنید. داده‌های دیتابیس در volume محلی Docker نگهداری می‌شوند.

## صفحات فروشگاه

- `/` صفحهٔ اصلی و ویترین
- `/products` جست‌وجو، فیلتر، مرتب‌سازی و صفحه‌بندی کاتالوگ
- `/products/[slug]` گالری، تنوع رنگ و سایز، موجودی و افزودن به سبد
- `/cart` سبد خرید ذخیره‌شده در مرورگر با به‌روزرسانی قیمت و موجودی از API
- `/account` ورود مشتری با کد یک‌بارمصرف، پروفایل، نشانی‌های ذخیره‌شده و تاریخچهٔ سفارش
- `/checkout` ثبت سفارش فقط برای مشتری واردشده با انتخاب نشانی ذخیره‌شده و رزرو موقت موجودی
- `/favorites` فهرست علاقه‌مندی‌های محلی مرورگر
- `/account` پیگیری وضعیت سفارش با شمارهٔ سفارش و تلفن گیرنده
- `/about`، `/contact`، `/help/faq`، `/help/shipping` و صفحات `/policies/*`

## API و پایگاه داده

API محلی در `http://127.0.0.1:4000/api/v1` اجرا می‌شود. مستندات OpenAPI در `/api/docs` و سلامت آمادگی دیتابیس در `/api/v1/health/ready` قرار دارد.

- `GET /categories` و `GET /products` و `GET /products/:slug` برای ویترین؛ فیلتر ترکیبی بر اساس دسته، جست‌وجو، قیمت، رنگ، سایز، موجودی و تخفیف
- `POST /checkout/quote` برای محاسبهٔ سمت سرور بر پایهٔ قیمت و موجودی جاری
- `POST /customer/auth/send-code` و `POST /customer/auth/verify-code` برای ورود/ساخت حساب مشتری با کد یک‌بارمصرف
- `GET/PATCH /customer/profile` و مسیرهای `/customer/addresses` برای ذخیرهٔ حساب و نشانی‌های تحویل
- `POST /orders` برای ثبت سفارش حساب‌محور با کلید جلوگیری از ثبت تکراری و رزرو ۱۵ دقیقه‌ای موجودی
- `POST /orders/track` برای نمایش محدود وضعیت سفارش و خط زمانی آن
- `GET /storefront/config` برای دریافت تنظیمات عمومی تم، بنرها و چیدمان صفحهٔ اصلی
- مسیرهای `/admin/*` برای ورود مدیر، داشبورد، مدیریت محصول و تنوع، دسته‌ها، بنرها، تم و چیدمان، گردش سفارش و اصلاح موجودی؛ عملیات مدیریتی احراز هویت و ثبت رویداد دارند

جزئیات قرارداد API مدیریت و راه‌اندازی امن مدیر اولیه در [docs/admin-api.md](docs/admin-api.md) آمده است.

در محیط توسعه، کد ورود به‌صورت آزمایشی در پاسخ API برمی‌گردد. برای بهره‌برداری واقعی باید سرویس پیامک انتخاب و کلیدها و متغیر `CUSTOMER_AUTH_SECRET` تنظیم شوند. هنوز درگاه پرداخت و روش ارسال تنظیم نشده‌اند؛ ثبت سفارش تراکنش بانکی انجام نمی‌دهد و سفارش پرداخت‌شده نیست. سورس کلاینت Flutter مدیر و پروژهٔ Android در `apps/admin-mobile` قرار دارند. APK دیباگ در `apps/admin-mobile/build/app/outputs/flutter-apk/app-debug.apk` ساخته شده است؛ برای گوشی واقعی باید نشانی API با IP شبکهٔ رایانه تنظیم شود و برای انتشار، API باید HTTPS داشته باشد.

داده‌ها و تصاویر فعلی کاتالوگ نمونه‌اند و باید پیش از فروش واقعی با اطلاعات، موجودی، اندازه‌ها، تصاویر و سیاست‌های واقعی PanizStyle جایگزین شوند. شمارهٔ پشتیبانی، ایمیل، زمان پاسخ‌گویی و قوانین مرجوعی هم هنوز از طرف فروشگاه تعیین نشده‌اند.

## اجرای دستی توسعه

در صورت نیاز به اجرای جداگانه، Docker Desktop باید فعال باشد. فایل‌های تنظیمات را از نمونه‌ها بسازید و سپس:

```powershell
Copy-Item database/.env.example database/.env -Force
docker compose --project-directory database -f database/compose.yaml up -d
cd apps/api
Copy-Item .env.example .env -Force
npm.cmd install
npm.cmd run prisma:generate
npm.cmd run prisma:migrate:deploy
npm.cmd run prisma:seed
npm.cmd run start:dev
```

در یک پنجرهٔ دیگر، از ریشهٔ پروژه `npm.cmd run dev` را اجرا کنید. API به Node.js نسخهٔ 20.19 یا بالاتر نیاز دارد.
