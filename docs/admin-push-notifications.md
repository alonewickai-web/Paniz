# اعلان‌های مدیریت

سفارش‌های تازه، پیام‌های مشتریان از سایت و پیام‌های ورودی ربات روبیکا در صندوق اعلان‌های سوپرادمین ذخیره می‌شوند. نشان زنگوله تعداد اعلان‌های خوانده‌نشده را نمایش می‌دهد و فهرست هر ۳۰ ثانیه در زمان استفاده از برنامه تازه می‌شود.

Firebase و ارسال پوش در این نسخه حذف شده‌اند. وقتی برنامه بسته باشد اعلان سیستمی ارسال نمی‌شود؛ پیام‌ها روی سرور باقی می‌مانند و با بازکردن برنامه دیده می‌شوند.

فقط سوپرادمین به صندوق اعلان‌های سیستمی دسترسی دارد. برای بروزرسانی برنامه از منوی «بروزرسانی» استفاده کنید.
