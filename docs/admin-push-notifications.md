# راه‌اندازی اعلان‌های پوش مدیر

کد صندوق اعلان سفارش تازه، پیام روبیکا و پیام فرم تماس سایت را در پایگاه داده نگه می‌دارد. ارسال پوش به گوشی از Firebase Cloud Messaging استفاده می‌کند و تا زمانی که مراحل زیر انجام نشود خاموش می‌ماند.

## تنظیم اپ اندروید

1. در Firebase Console یک پروژه بساز یا پروژهٔ موجود را انتخاب کن و اپ Android با شناسهٔ `com.panizstyle.panizstyle_admin` اضافه کن.
2. فایل `google-services.json` همان اپ را در مسیر `apps/admin-mobile/android/app/google-services.json` بگذار.
3. اپ را با نسخهٔ جدید بساز و نصب کن. مدیر باید اپ را یک بار باز کند، وارد حساب سوپرادمین شود و اجازهٔ اعلان را بدهد.

## تنظیم سرور

1. در Firebase Console از بخش تنظیمات پروژه، یک کلید خصوصی Service Account بساز و فایل JSON را فقط روی رایانهٔ خودت نگه دار.
2. فایل JSON را به یک رشتهٔ Base64 تک‌خطی تبدیل کن و همان مقدار را در متغیر `FIREBASE_SERVICE_ACCOUNT_BASE64` فایل محرمانهٔ `/opt/panizstyle/.env.server` قرار بده. خود فایل JSON یا مقدار Base64 را در Git، پیام یا لاگ قرار نده.
3. فایل `.env.server` باید دسترسی محدود داشته باشد. سپس نسخهٔ API را همراه migration پایگاه داده منتشر کن؛ اسکریپت انتشار پروژه migration را اجرا می‌کند.

اگر Firebase تنظیم نشده باشد، اعلان‌ها در صندوق داخل اپ ذخیره می‌شوند ولی پوش ارسال نمی‌شود. پیام‌های پوش عمداً فقط نوع رویداد را نشان می‌دهند؛ متن و اطلاعات مشتری فقط پس از ورود به اپ دیده می‌شود.

## محدودیت دستگاه

برای دریافت پوش، اپ باید دست‌کم یک بار باز شده و مجوز اعلان داده شده باشد. اگر Android اپ را از تنظیمات دستگاه به‌اجبار متوقف کند، معمولاً باید اپ را دوباره باز کرد تا دریافت پوش از سر گرفته شود. دریافت FCM به سرویس‌های Google Play روی دستگاه هم وابسته است.
