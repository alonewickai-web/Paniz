# بروزرسانی برنامهٔ مدیریت از سرور فروشگاه

## مسیر کار مدیر

1. نسخهٔ امضاشدهٔ APK را با همان کلید انتشار همیشگی بسازید.
2. برنامهٔ مدیریت → منوی همبرگری → «بروزرسانی» → «انتشار نسخه روی سرور».
3. فایل APK را انتخاب کنید، یادداشت نسخه را بنویسید و انتشار را تأیید کنید.
4. مدیران دیگر از همین صفحه نسخهٔ تازه را بررسی و دانلود می‌کنند. برنامه SHA-256، شناسهٔ بسته، امضای انتشار و شمارهٔ ساخت را پیش از نصب کنترل می‌کند؛ سپس Android تأیید نهایی نصب را می‌گیرد.

فایل نسخه‌ها روی میزبان خود فروشگاه و کنار سایر بارگذاری‌های API نگه داشته می‌شود. نسخه‌های پیشین برای بازگشت حفظ می‌شوند. انتشار با مجوز `system.release` محدود است و در گزارش فارسی ثبت می‌شود.

## آماده‌سازی نخستین نسخه

این تغییر API به دو مهاجرت Prisma نیاز دارد. آن‌ها همراه فرایند استقرار عادی API و به شکل افزایشی اجرا می‌شوند. پوشهٔ بارگذاری باید روی فضای پایدار سرور باشد و پراکسی HTTPS مسیر `/uploads/` را به API برساند. مطمئن شوید محدودیت اندازهٔ بدنهٔ پراکسی با APK فروشگاه سازگار است.

نسخهٔ قبلی برنامه به صفحهٔ بروزرسانی مجهز نیست؛ APK جدید باید یک‌بار از روش نصب فعلی روی هر دستگاه نصب شود. از آن پس، نسخه‌های بعدی از سرور بررسی می‌شوند.

## نگهداری کلید امضا

هر APK باید با همان keystore، alias و گواهی نسخهٔ نصب‌شده ساخته شود. تعویض یا گم‌شدن کلید اجازهٔ نصب بروزرسانی روی نصب فعلی را نمی‌دهد. keystore و فایل تنظیم کلید را در مخزن یا سرور بارگذاری نکنید و نسخهٔ پشتیبان رمزگذاری‌شدهٔ آن را جدا نگه دارید.
