# PanizStyle Storefront Override

This page follows the user's supplied PANIZ storefront reference image and the requirements in the project brief. Those direct references take precedence over the generic palette returned by the design search.

## Direction

- Persian-first RTL apparel storefront with a light, airy, editorial feel.
- Use warm white surfaces, coral rose as the main shopping action, and soft peach, mint, lilac, and sand as supporting accents.
- Keep product photography prominent; use calm, low-contrast borders and small rounded corners instead of heavy block treatments.
- The mobile storefront uses a fixed five-item bottom navigation and comfortably sized touch controls.

## Type and interaction

- Use Vazirmatn with a system fallback for legible Persian text.
- Primary body text is 15px on desktop and at least 14px on smaller screens when practical; compact labels can be smaller where their context remains clear.
- Maintain visible keyboard focus, descriptive image alternatives, semantic labels, and reduced-motion support.
- Keep transitions subtle (150–220ms) and preserve reserved image dimensions to avoid layout shifts.
